人机协作 · 判断力与决策力

用 AI 校准判断：决策闭环架构

每个决策都走完四步：原始信息 → 决策事实 → 假设推断 → 结果回填。人和 Agent 各自写下概率与依据，结果出来后对照，找出谁的思维模型需要修正。闭环积累得越多，Agent 给出的建议越贴近你的真实情况。

一条完整链路

四个模块，真假性质各不相同

01

原始信息

可真可假 · 不完整

我们已知、感知到、理解到的信息。

  • 信息本身可能是假的
  • 对世界的感知和理解可能有偏差
  • 已知信息往往不全面
02

决策事实

确定为真

基于原始信息做出的决定：我决定做某件事。

这是唯一确定为真的一环，因为决定是我亲自下的。

03

假设推断

概率 + 依据

人和 Agent 都读取 01 和 02，各自对结果做出判断。

A · 人的判断
结论会成还是会败
概率多大把握
依据我的经验与理由
B · Agent 判断
结论会成还是会败
概率预测成功率
依据全网数据 + 上下文
✎ 双方的论据和判断依据都必须记录下来。没有依据，复盘时就无法定位错在哪里。
04

结果回填

客观结果

一段时间后结果出来，把实际结果和复盘写回同一条记录。

拿结果分别对照 A、B 两份判断。

↺ 纠偏：修正思维模型，下一次决策带着新的认知进入

结果出来后：怎么纠偏

用实际结果分别检验人和 Agent 的判断，四种情况对应四种处理

Agent 判断对
Agent 判断错
我判断对
双方一致，结果符合预期

思维模型有效，继续沿用。

我对，Agent 错

记录 Agent 的盲区：它缺了哪些上下文，下次补给它。

我判断错
我错，Agent 对

对照 Agent 的依据，修正自己的思维模型。

双方都错

回到 01 原始信息：信息是假的、不全，还是对世界的理解错了。

核心信号：我认为能成但没成，说明我的思维模型错了，需要纠偏；我和 Agent 判断相反时，用结果对照，谁错修正谁。

日积月累：决策库让 Agent 越来越懂你

每条闭环都是一条带依据和结果的样本

一条条闭环

信息、决策、双方概率与依据、实际结果、复盘，完整存成一条记录。

个人决策库

积累大量「判断 vs 结果」的对照，暴露你在哪类问题上常判断失准。

下一次决策
